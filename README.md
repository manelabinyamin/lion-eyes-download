# Lion Eyes · עיני אריה

Eye gaze games for children who are learning to use a computer with their eyes. Windows app.

**Download:** [Lion-Eyes-Setup.exe](https://github.com/manelabinyamin/lion-eyes-download/releases/latest/download/Lion-Eyes-Setup.exe)

1. Run the installer. Windows may show "Windows protected your PC" once: choose *More info* → *Run anyway*.
2. Connect the computer to the internet, type the activation code you received, and press *Activate*.
3. After that the games work without internet. Updates install by themselves when the computer is online.

The app needs an activation code. This page only holds the installer.
